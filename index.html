1 Nguồn dữ liệu

Cách lấy Google API Key (miễn phí · làm 1 lần)
  1. Vào console.cloud.google.com → đăng nhập Google.
  2. Tạo Project mới (góc trên, cạnh logo) → đặt tên gì cũng được.
  3. Menu trái → APIs & Services → Library → tìm Google Sheets API → bấm Enable.
  4. Menu trái → Credentials → Create Credentials → API key. Copy chuỗi AIza....
  5. (Khuyên dùng) Bấm vào key vừa tạo → API restrictions → chọn Restrict key → tick Google Sheets API → Save. Như vậy key chỉ đọc được Sheets, không dùng được việc khác.
  6. Google Sheet của bạn để chế độ Bất kỳ ai có đường liên kết → Người xem.
📂 Kéo-thả hoặc bấm để chọn file .xlsx đã xuất trước đó
Dùng khi bạn muốn mở lại bản đã làm để chỉnh, không cần đọc lại Google Sheet.
